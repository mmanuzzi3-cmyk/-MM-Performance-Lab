MM PERFORMANCE LAB – APP V1.0

CONTENUTO
- index.html: applicazione
- manifest.json: configurazione installazione
- sw.js: funzionamento offline

AVVIO RAPIDO SU COMPUTER
1. Apri la cartella.
2. Avvia un piccolo server locale, per esempio:
   python -m http.server 8080
3. Apri nel browser: http://localhost:8080

INSTALLAZIONE SU TABLET
L'app deve essere pubblicata su un indirizzo HTTPS.
Poi:
- Android/Chrome: menu ⋮ > Aggiungi a schermata Home / Installa app.
- iPad/Safari: Condividi > Aggiungi alla schermata Home.

DATI
I dati vengono salvati localmente nel browser del dispositivo.
Usa Impostazioni > Esporta backup JSON per non perderli.
